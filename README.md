Nigeria in Numbers — a national statistics explorer for Nigeria: headline indicators, GDP and inflation charts, population, all 36 states + FCT from the 2006 census, and a CPI basket calculator. Every figure is labelled with its source and year (NBS, World Bank, UN, NPC, UNDP). Static files only — no network requests, no build step.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 in a browser.

## Pages

- **Overview** — headline indicators, GDP and population charts, largest states
- **Economy** — switchable GDP / GDP-per-capita / real-growth charts and data tables, CSV download
- **People** — population trend, top-10 states, population by geopolitical zone, life expectancy, HDI, poverty
- **States** — searchable, sortable, zone-filterable table of all 36 states + FCT with a detail panel and CSV download
- **Prices** — CPI inflation chart, a "what money used to buy" calculator, and an editable monthly-basket breakdown by NBS CPI weights
- **Sources** — every source, what it was used for, and method notes
